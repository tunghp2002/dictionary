# Contributing

Contributions are welcome. Keep each correction tied to its existing
`sense_id`, explain what is wrong, and cite a reliable source when changing a
sense, grammatical fact, usage label, or lexical relation.

Run the full test suite before submitting a change:

```bash
.venv/bin/python -m unittest discover -s tests
```

By submitting a contribution, you agree to license code, tests, schemas, and
documentation under Apache-2.0, and dataset contributions under CC BY-SA 4.0.
Do not submit content that you do not have permission to redistribute. Preserve
the attribution and provenance described in `NOTICE.md` and
`DATA_LICENSES.md`.
